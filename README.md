# 抖音电商数据看板

参考618复盘文档格式搭建的在线数据看板系统。

## 📁 文件结构

```
douyin-dashboard/
├── index.html      # 前端页面（主看板）
├── server.py       # 后端服务（Python）
├── data/           # 数据存储目录
│   └── dashboard_data.json
└── README.md       # 说明文档
```

## 🚀 快速启动

### 1. 启动服务

```bash
cd d:\mydata\桌面\skill\douyin-dashboard
python server.py
```

### 2. 访问看板

浏览器打开: **http://127.0.0.1:8080**

## 📊 功能模块

### 1. 总览 (Overview)
- 核心KPI展示：GMV、市占率、控比、动销直播间
- 品牌GMV对比图
- 渠道占比饼图
- 竞品对比卡片

### 2. 销售达成 (Sales)
- 美的系市占分析
- 分门体价格段分析表格
- 核心问题 & 改善动作

### 3. 直播间分析 (Live)
- 各品牌动销直播间数量对比
- 渠道控比雷达图
- TOP10直播间排名

### 4. 达人分析 (KOL)
- 达人类型分布（垂类/头达/自然流）
- 品牌达人成交对比
- H2目标规划

### 5. 推广效果 (Promotion)
- 花费趋势图
- ROI变化图
- 分直播间推广数据表

### 6. 短视频 (Video)
- 播放量 & 引流趋势
- 爆款视频TOP5
- 问题 & 亮点分析

### 7. 客服数据 (Service)
- 咨询量、转化率、响应时间、满意率
- 风险点 & 解决措施

### 8. 竞品对比 (Competitor)
- 品牌综合对比表
- GMV对比柱状图
- 市占率饼图

### 9. 数据录入 (Import)
- Excel文件上传
- 手动录入表单
- 历史数据查看

## 🔌 API接口

### 获取所有数据
```
GET /api/data
```

### 获取指定类型数据
```
GET /api/data/{type}
```
type: overview / sales / live / kol / promotion / video / service / competitor

### 保存数据
```
POST /api/data
Content-Type: application/json

{
  "type": "sales",
  "date": "2026-06-18",
  "brand": "midea",
  "gmv": 25000,
  "share": 25.57
}
```

## 📋 数据格式参考

参考618复盘文档的12个模块：

| 模块 | 核心指标 |
|------|----------|
| 销售达成 | GMV、市占率、控比、均价 |
| 分门体 | 门体权重、价格段分布 |
| 直播间 | 动销数、TOP100、控比 |
| 品旗渠道 | 店铺GMV、自播/达播/商品卡 |
| 达人 | 头达/垂类/自然流成交 |
| 分销 | 生态客户GMV、TOP客户 |
| 冷柜 | 冷柜销售、份额 |
| 推广 | 花费、ROI、费率 |
| 短视频 | 播放量、引流、爆款数 |
| 客服 | 咨询量、转化率、满意率 |
| 运营 | SOP执行 |
| 华凌 | 出库、GMV、市占 |

## 🎨 设计特点

- **深色主题**：专业数据看板风格
- **响应式布局**：支持桌面和移动端
- **图表可视化**：Chart.js 实现多种图表
- **模块化设计**：9个功能模块独立切换
- **数据驱动**：前后端分离，支持动态更新

## 🔧 技术栈

- **前端**: HTML5 + CSS3 + JavaScript
- **图表**: Chart.js 4.4.0
- **图标**: Material Design Icons
- **后端**: Python 3 (http.server)
- **数据**: JSON
